Чтобы добавить ярлык в меню "Пуск" в Linux Mint Cinnamon через консоль, нужно создать файл `.desktop` для приложения в нужной директории. Вот пошаговая инструкция:

1. **Откройте терминал**.

2. **Создайте файл ярлыка**:
   - Перейдите в директорию для пользовательских ярлыков:
```bash
cd ~/.local/share/applications
```
   - Создайте новый файл `.desktop` для приложения. Например, для добавления ярлыка браузера Firefox создайте файл `firefox.desktop`:
     ```bash
     nano firefox.desktop
     ```
3. **Добавьте информацию о приложении**:
   В открывшемся редакторе `nano` вставьте следующие строки, заменяя значения на те, которые подходят для вашего приложения:
```ini
[Desktop Entry]
Version=1.0
Name=Firefox
Comment=Web Browser
Exec=firefox %u
Icon=firefox
Terminal=false
Type=Application
Categories=Network;WebBrowser;
```
   Здесь:
   - **Name** — имя, отображаемое в меню.
   - **Comment** — описание, которое можно увидеть при наведении на значок.
   - **Exec** — команда для запуска приложения. `%u` используется для передачи URL (если применимо).
   - **Icon** — имя иконки для приложения. Система попытается найти значок с таким именем.
   - **Terminal** — если установлено `true`, приложение откроется в терминале; если `false` — в графическом интерфейсе.
   - **Categories** — категории для классификации приложения в меню.

4. **Сохраните файл и выйдите**:
   - В `nano` нажмите `Ctrl + O` для сохранения, затем `Ctrl + X` для выхода.

5. **Сделайте файл исполняемым**:
```bash
chmod +x firefox.desktop
```
6. **Перезапустите меню (опционально)**:
   В большинстве случаев меню "Пуск" автоматически обновится, и новое приложение появится. Если этого не произошло, попробуйте перезапустить Cinnamon:
```bash
cinnamon --replace &
```
Теперь ваш ярлык должен появиться в меню "Пуск".
