Для подключения к FTP и SSH можно использовать формат DSN.

Пример для SSH:
```
sftp://user@127.0.0.1:2222/home/user
```
Пример для FTP:
```
ftp://user@127.0.0.1:2222/home/user
```
`sftp://` и `ftp://` - протокол для SSH и FTP
`user` - имя пользователя
`127.0.0.1` - имя хоста
`2222` - порт
`/home/user` - путь на сервере по умолчанию
