Команда `mkisofs` (или ее современный эквивалент `genisoimage`) используется для создания ISO-образов из данных. Она позволяет собрать каталог или файлы в единый ISO-образ, который можно использовать, например, для записи на диск или для монтирования.

---

### Пример создания ISO-образа с помощью `mkisofs`

1. **Базовый пример**

```bash
mkisofs -o output.iso /path/to/source
```

- `-o output.iso` — указывает имя создаваемого ISO-образа.
- `/path/to/source` — путь к каталогу или файлам, которые будут включены в образ.

2. **Указание имени тома**

```bash
mkisofs -o output.iso -V "MY_LABEL" /path/to/source
```

- `-V "MY_LABEL"` — задает метку тома (максимум 32 символа).

3. **Создание загрузочного ISO-образа (bootable ISO)** Если вы хотите создать загрузочный образ:

```bash
mkisofs -o bootable.iso -b isolinux.bin -c boot.catalog -no-emul-boot -boot-load-size 4 -boot-info-table /path/to/source
```

- `-b isolinux.bin` — указывает загрузочный файл (например, `isolinux.bin`).
- `-c boot.catalog` — указывает файл каталога загрузочных секторов.
- `-no-emul-boot` — задает режим загрузки (без эмуляции).
- `-boot-load-size 4` — задает количество блоков для загрузки.
- `-boot-info-table` — добавляет таблицу загрузочной информации.

4. **Поддержка файлов больше 4 ГБ (UDF/ISO9660)** Если в образе есть файлы, размер которых превышает 4 ГБ:

```bash
mkisofs -o largefile.iso -udf -iso-level 3 /path/to/source
```

- `-udf` — добавляет поддержку UDF (Universal Disk Format).
- `-iso-level 3` — поддержка файлов >4 ГБ.

5. **Добавление времени создания**

```bash
mkisofs -o output.iso -R -J -V "MY_LABEL" -graft-points /path/to/source
```

- `-graft-points` позволяет гибко добавлять файлы и каталоги в образ, сохраняя временные метки.

---

### Полезные опции

- `-R` — включить Rock Ridge для сохранения POSIX-атрибутов файлов.
- `-J` — включить Joliet для поддержки длинных имен файлов в Windows.
- `-T` — создать файл `TRANS.TBL` для отображения длинных имен в системах, не поддерживающих Joliet или Rock Ridge.
- `-v` — подробный вывод процесса.

---

### Проверка созданного ISO-образа

После создания ISO-образа вы можете смонтировать его для проверки:

```bash
sudo mount -o loop output.iso /mnt
```

После проверки отмонтируйте:

```bash
sudo umount /mnt
```

---

### Пример создания ISO-образа с несколькими источниками

Если нужно объединить файлы из разных каталогов:

```bash
mkisofs -o output.iso -R -J -V "MY_LABEL" \
  /path/to/source1 \
  /path/to/source2
```

---

Если `mkisofs` недоступен, можно использовать аналог `genisoimage`, который имеет аналогичный синтаксис.
